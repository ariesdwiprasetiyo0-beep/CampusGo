## ⚡ Quick Reference

### After XcodeGen Generates Project

```
Files to COMMIT to Git:
✅ project.yml              (Configuration - always commit)
✅ Makefile                 (Commands - always commit)
✅ generate.sh              (Scripts - always commit)
✅ CampusApp/               (Source - always commit)
✅ CampusAppTests/          (Tests - always commit)

Files to NOT commit to Git:
❌ CampusApp.xcodeproj/     (Generated - don't commit)
❌ build/                   (Build artifacts - don't commit)
❌ .xcodeproj/pbxproj       (Generated - don't commit)
❌ DerivedData/             (Build cache - don't commit)
```

### For CI/CD Pipelines

```
.github/workflows/build.yml

- name: Generate Xcode Project
  run: |
    xcodegen generate

- name: Build
  run: |
    xcodebuild build \
      -scheme CampusApp \
      -configuration Release

- name: Test
  run: |
    xcodebuild test \
      -scheme CampusApp
```

## 📋 Checklist

After each step, verify:

```
STEP 1: XcodeGen Installation
  □ xcodegen version (shows version)
  □ which xcodegen (shows path)

STEP 2: Project Generation
  □ CampusApp.xcodeproj exists
  □ project.pbxproj is not empty
  □ No error messages

STEP 3: Xcode Opens
  □ Project shows in Xcode sidebar
  □ CampusApp target visible
  □ CampusAppTests target visible
  □ 38 Swift files listed

STEP 4: Signing Configured
  □ No red code signing warnings
  □ Team selected in Signing & Capabilities
  □ Provisioning profile shows

STEP 5: Runs Successfully
  □ Build succeeds (Cmd+B)
  □ App launches on simulator (Cmd+R)
  □ No runtime crashes
  □ Tests pass (Cmd+U)
```

## 🚀 Automation

### Using Make

```bash
make setup          # One-command setup (needs XcodeGen installed)
make generate       # Regenerate project
make build          # Build Debug
make test           # Run tests
make open           # Open in Xcode
```

### Using Shell Scripts

```bash
bash generate.sh    # Auto-setup with checks
bash generate-manual.sh  # Manual with instructions
```
